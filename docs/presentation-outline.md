# Presentation outline (5–7 minutes)

1. Problem: fake academic credentials and slow manual checking.
2. Actors and design: issuer, graduate, employer, web app, API, off-chain store, Polygon Amoy registry.
3. Live flow: issue a synthetic credential, show signature/hash registration, verify as employer, revoke, verify again.
4. Security choices: signatures detect unauthorized changes; chain stores hashes/status only; secrets and personal claims stay off-chain.
5. Limits and next steps: testnet, demo issuer key, local JSON storage, W3C-style shape rather than complete standards compliance; production needs institutional identity, secure storage, access controls, key rotation, privacy review, and standards-compliant proof tooling.
6. Each member explains their component and one challenge learned.
